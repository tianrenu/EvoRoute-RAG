## 核心设计实现

### 1. LangGraph 状态图

```
Router → Retriever → Quality Gate → [pass/pass_with_log] → Generator → END
                          ↓ [reretrieve]
                     reretrieve → Retriever (循环)
```

- **状态定义**：`AgenticRAGState`（TypedDict），包含 query、质量指标、attribution_evidence 等 13 个字段
- **条件路由**：Quality Gate 根据 Q 分数决定 pass / pass_with_log / reretrieve

### 2. Quality Gate 综合质量评分

```
Q = 0.40·S + 0.25·M + 0.20·A + 0.15·C
```

| 指标 | 含义 | 实现方式 |
|------|------|---------|
| S | 检索文档与查询的向量相似度均值 | `mean([doc.score])` |
| M | top-1 与 top-2 相似度之差 | `docs[0].score - docs[1].score` |
| A | 检索文档一致性 | score 标准差倒数归一化 |
| C | 关键词实体覆盖 | jieba 分词 + 关键词匹配 |

**决策逻辑**：
- Q >= 0.75 → pass（高置信度）
- Q ∈ [0.55, 0.75) → pass_with_log（灰色地带）
- Q < 0.55 且 reretrieve_count < 3 → reretrieve
- Q < 0.55 且 reretrieve_count >= 3 → pass_with_log（兜底）

### 3. gap_type 启发式判定

| 条件 | gap_type |
|------|----------|
| coverage_score < 0.4 | keyword_missing |
| top1_margin < 0.05 且文档数 > 2 | precision_dilution |
| mean_similarity < 0.4 | doc_missing |

### 4. LLM 调用容错

- **Circuit Breaker**：连续 5 次失败 → 熔断 60 秒 → HALF_OPEN 恢复尝试
- **指数退避重试**：1s → 2s → 4s（最多 3 次）
- **超时控制**：单次 30 秒
- **API 格式**：MiniMax abab6.5-chat（OpenAI 兼容）

### 5. attribution_evidence 输出

完整包含设计书要求的所有字段：
```python
{
    "S": float, "M": float, "A": float, "C": float, "Q": float,
    "gap_type": str,
    "top_k_max_sim": float, "top1_sim": float,
    "has_correct_entity": bool, "reretrieve_count": int
}
```

## 使用方式

```python
from evoroute_rag.layer2 import AgenticRAGPipeline

pipeline = AgenticRAGPipeline(
    qdrant_url="http://localhost:6333",
    llm_config={
        "base_url": "https://api.minimaxi.com/v1",
        "api_key": "your-key",
        "model": "abab6.5-chat",
        "embedding_api_key": "your-dashscope-key",
    },
)

result = pipeline.run(
    query="图书馆几点开门",
    skill_config={
        "semantic_type": "factual_query",
        "retrieval": {"top_k": 5, "boost_keywords": ["开放时间"]},
    },
)

print(result["final_answer"])
print(result["quality_score"])
print(result["attribution_evidence"])
```

## 与 L1/L3 的接口约定

| 接口方向 | 数据 | 说明 |
|----------|------|------|
| L1 → L2 | `skill_config` | 包含 retrieval（top_k, filter_metadata, boost_keywords）和 semantic_type |
| L2 → L3 | `attribution_evidence` | Quality Gate 输出的归因证据字典，供 L3 错误归因使用 |
